# API Docs Writer

Produce readable API documentation.

## Core Workflow

1. Understand the endpoint(s): method, path, purpose, auth.
2. Document parameters (path, query, body) with types, required status, and descriptions.
3. Show request and response examples.
4. List possible status codes and error responses.
5. Note authentication, rate limits, and versioning if relevant.
6. Keep language consistent and developer-friendly.

## Sections to Include

- Overview
- Authentication
- Endpoints (with examples)
- Error handling
- Changelog / version notes (if applicable)
